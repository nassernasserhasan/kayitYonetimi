# Kayıt Yönetim Sistemi (Kayit Yonetim Sistemi)

## Proje Açıklaması
Bu proje, C++ kullanarak kayıtların dosya üzerinde eklenmesi, aranması, güncellenmesi, silinmesi ve listelenmesi işlemlerini gerçekleştiren basit bir sistemdir. Kullanıcı dostu bir menü aracılığıyla, kullanıcı ihtiyacı olan işlemleri kolayca yapabilir.

## Özellikler
- Etkileşimli kullanıcı arayüzü ile işlem seçme.
- Kayıtları kolayca ekleme, güncelleme ve silme.
- Tüm kayıtlar için ortalama puan hesaplama.
- Verilerin güvenli bir şekilde saklanması için ikili dosya kullanımı.

## Kullanım
1. Projeyi bilgisayarınıza indirin veya klonlayın.
2. C++ geliştirme ortamınızda projeyi açın (Visual Studio, Code::Blocks vb.).
3. Programı çalıştırın.
4. Ekranda görünen menüden işlemleri seçin:
   - **1** Yeni kayıt eklemek için.
   - **2** Tüm kayıtları görüntülemek için.
   - **3** Kayıt ID'sine göre arama yapmak için.
   - **4** Kayıt güncellemek için.
   - **5** Kayıt silmek için.
   - **6** Ortalama puanı hesaplamak için.
   - **0** Programdan çıkmak için.

## Çalışma Ortamı
- Programlama Dili: C++
- İşletim Sistemi: C++ destekleyen her işletim sisteminde çalışabilir (Windows, Linux, macOS).
- Ek kütüphane gereksinimi bulunmamaktadır, sadece C++ temel kütüphaneleri kullanılmıştır.

## Kurulum
1. Bilgisayarınızda bir C++ derleyicisinin yüklü olduğundan emin olun.
2. Bu depoyu indirin veya klonlayın.
3. Projeyi C++ geliştirme ortamınızda açın.
4. Programı çalıştırın.
